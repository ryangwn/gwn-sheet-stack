# sheet-stack

A headless presentation-layer stack for React (and Svelte). sheet-stack owns the **FSM, motion coordinator, and gesture seam**; you bring the surface — a plain `<div>`, [Radix Dialog](https://www.radix-ui.com/primitives/docs/components/dialog), [vaul](https://vaul.emilkowal.ski/), or anything else.

## Why headless

Surface chrome (modal, drawer, sheet) is opinionated and product-specific. Stack orchestration is not. sheet-stack used to ship `Modal`, `Panel`, and `PushScreen` built-ins; from `0.1.0` they are gone — replaced by a tiny adapter contract.

See **Adapters/PlainDiv**, **Adapters/RadixDialog**, **Adapters/Vaul** for end-to-end examples (each under ~60 lines).

## Quick start

```bash
bun add @gwn-sheet-stack/react @gwn-sheet-stack/core
```

### 1. Create a store and wrap your app

```tsx
import { useMemo } from 'react';

import { createStackStore } from '@gwn-sheet-stack/core';
import { StackProvider, Stage } from '@gwn-sheet-stack/react';

function App() {
  const store = useMemo(() => createStackStore({ mountWindow: 3 }), []);

  return (
    <StackProvider value={store}>
      <YourApp />
      <Stage registry={{ modal: MyModalAdapter }} />
    </StackProvider>
  );
}
```

### 2. Push a layer from anywhere

```tsx
import { useStack } from '@gwn-sheet-stack/react';

function TriggerButton() {
  const { push } = useStack();
  return <button onClick={() => push({ kind: 'modal' })}>Open modal</button>;
}
```

### 3. Build an adapter

The adapter contract is one hook + two refs:

```tsx
import { useLayerPresentation } from '@gwn-sheet-stack/react';

// `duration` is in seconds (typical 0.2–0.5).
const ENTER = { kind: 'modal', direction: 'in', spring: { duration: 0.42, bounce: 0.18 } } as const;
const EXIT = { kind: 'modal', direction: 'out', spring: { duration: 0.22, bounce: 0 } } as const;

function MyModalAdapter() {
  const { surfaceRef, backdropRef, dismiss } = useLayerPresentation({ enter: ENTER, exit: EXIT });
  return (
    <>
      <div ref={backdropRef} onClick={dismiss} style={{ position: 'fixed', inset: 0, background: 'rgba(0,0,0,0.5)', opacity: 0 }} />
      <div ref={surfaceRef} role="dialog" style={{ position: 'fixed', top: '50%', left: '50%' }}>
        <h2>Hello!</h2>
      </div>
    </>
  );
}
```

The FSM owns mount/unmount — adapters wrap whichever third-party component you like with `open` pinned to `true` and route dismiss intents through `dismiss()`.

## Opt-in styles

```ts
import '@gwn-sheet-stack/react/styles';
```

Adds default backdrop dimming, host scaling, and `will-change` hints. Fully overridable via CSS.
